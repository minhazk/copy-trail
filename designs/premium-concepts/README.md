# Copy Trail premium design concepts

Generated design mockups for comparison; these are not captures of the running app.

- Liquid Glass: smoky dark translucency with subtle blue/green desktop light, a fine luminous edge, and flat separated rows.
- Soft Carbon: warm matte charcoal with raised cards and restrained ambient shadows.
- Floating Ink: a floating search capsule separated from the near-black list surface.

Created with the built-in image generation tool. Reference: the user-supplied macOS monitoring popover, used for glass material only.

Prompt summary: create three equally sized front-on dark macOS clipboard menu-bar popover screenshots, high-quality native typography, search and ellipsis menu, no title header or status footer, four clipboard entries including long text with Expand and an architectural image. Keep row highlights quiet, and remove controls inset and vertically centered. Make Liquid Glass match the reference's smoky translucency, illuminated rim and blue/green desktop light; make the other alternatives materially different in composition and surface. In the refinement pass, remove all leading document/link/text icons, align text at the normal inner padding, and replace solid circular red remove buttons with plain red x glyphs while preserving the rest of the design.
